# puripuri.dev

ぷりぷり（[bafubafu-bafuu](https://github.com/bafubafu-bafuu)）のポートフォリオサイトです。プロフィールや作ったもの（Chrome 拡張機能など）を掲載しています。

- 公開URL: https://puripuri.dev

## 技術スタック

- Next.js 16（App Router / 静的エクスポート）
- React 19 / TypeScript
- CSS（`src/app/globals.css` に手書き）

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

`out/` に静的ファイルが出力されます。

## Lint

```bash
npm run lint
```
